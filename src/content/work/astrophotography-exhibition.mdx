## About

The competition was based about the topics "From the shadows" and "Questions and Answers", to which I answered with this collection of photographs
showing several astrophotography targets. The project description and the interview with the first 3 places can be found below:

- [Astrophotography competition course page (Czech)](https://cw.fel.cvut.cz/b252/courses/a7b33dif/06_sinslavy)
- [FEL ČVUT article about the exhibition and projects (Czech)](https://fel.cvut.cz/cs/aktualne/novinky/84499-astrofotografie-i-snimky-bezdomovcu-studenti-cvut-predstavili-sve-projekty-na-tema-ze-stinu-q-a)
- [Gallery](http://bresson.felk.cvut.cz/index.php?/category/241)
