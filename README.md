# swpelc.eu

Jakub Pelc's static portfolio, built with Astro and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run check
npm run build
npm run test:routes
```

The site is deployed to GitHub Pages from `main` using the workflow in `.github/workflows/deploy.yml`.

Project and page copy lives in `src/content/`. Images imported by content live in `src/assets/images/`; stable downloadable files such as PDFs and audio recordings live in `public/`.
